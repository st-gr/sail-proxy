# SAP Cloud Identity Services sign-in

The setup guide for sign-in with SAP Cloud Identity Services (IAS, OpenID Connect) to the Admin Cockpit is part of the sail-proxy documentation site:

- [SAP Cloud Identity Services sign-in](https://st-gr.github.io/sail-proxy/deploy/auth-ias)
- [Authentication providers](https://st-gr.github.io/sail-proxy/deploy/authentication)

This folder holds the Dex configuration templates that `docker/setup-docker.js` and `kyma/scripts/setup-kyma.js` render for the provider.
