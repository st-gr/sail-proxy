# LDAP/Active Directory sign-in

The setup guide for LDAP/Active Directory sign-in to the Admin Cockpit is part of the sail-proxy documentation site:

- [LDAP/Active Directory sign-in](https://st-gr.github.io/sail-proxy/deploy/auth-ldap)
