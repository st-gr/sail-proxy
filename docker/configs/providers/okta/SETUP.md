# Okta SAML sign-in

The setup guide for Okta SAML sign-in to the Admin Cockpit is part of the sail-proxy documentation site:

- [Okta SAML sign-in](https://st-gr.github.io/sail-proxy/deploy/auth-okta)
- [Authentication providers](https://st-gr.github.io/sail-proxy/deploy/authentication)

This folder holds the Dex configuration templates that `docker/setup-docker.js` and `kyma/scripts/setup-kyma.js` render for the provider.
