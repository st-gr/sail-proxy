# sail-proxy Ollama service

The Ollama service is an adapter that accepts Ollama API requests, translates them to the OpenAI format and forwards them to the sail-proxy gateway, so Ollama clients can use SAP AI Core models.

- [Ollama service developer guide](https://st-gr.github.io/sail-proxy/developer/ollama-service)
- [Ollama API reference](https://st-gr.github.io/sail-proxy/reference/ollama-api)
