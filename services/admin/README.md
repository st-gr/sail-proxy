# sail-proxy admin service

The admin service is the SAP CAP application behind the Admin Cockpit: it manages API keys, users, quotas, AWS credentials, the gateway configuration and usage analytics, and serves the cockpit's UI5 apps.

- [Admin service developer guide](https://st-gr.github.io/sail-proxy/developer/admin-cockpit)
- [Admin Cockpit user guide](https://st-gr.github.io/sail-proxy/guide/cockpit/overview)
