# SAIL-PROXY User Guide
*Multi-provider AI Gateway for SAP AI Core*
**Author:** *st-gr*

![SAIL-PROXY Logo](/docs/assets/sail-proxy-logo-640x457.png)

## Abstract

SAIL-PROXY is a powerful AI gateway that enables applications using OpenAI, Anthropic, AWS Bedrock, OpenRouter, or Ollama API formats to seamlessly access SAP AI Core Foundation Models. This unified orchestration API provides enterprise-grade security, monitoring, and management capabilities while maintaining compatibility with popular AI development tools.

Whether you're using Claude Code, GitHub Copilot, or building custom AI applications, SAIL-PROXY acts as your bridge to SAP's enterprise AI infrastructure with comprehensive access control and usage analytics.
