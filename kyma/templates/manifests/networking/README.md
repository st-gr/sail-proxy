# sail-proxy Kyma networking manifests

This folder holds the templates that `kyma/scripts/setup-kyma.js` renders for a public deployment: the streaming VirtualService and EnvoyFilter, PeerAuthentication, DestinationRules and the health check protection. The APIRule templates (`apirule.yaml`, `apirule-examples.yaml`) are rendered and removed again, because the VirtualService takes all traffic. The IP allowlist and Cloud Connector tunnel policies are generated by the scripts, not templated here.
