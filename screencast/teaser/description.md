# sail-proxy teaser: description texts

## YouTube (full version)

sail-proxy: an enterprise LLM gateway for SAP AI Core. Free. From the community, for the community.

One gateway between your tools and SAP AI Core: Claude Code, Claude Desktop, Codex, GitHub Copilot, Gemini CLI, pi,
opencode, Open WebUI and n8n, and Claude Code in NVIDIA OpenShell sandboxes on Kyma, on the models your SAP AI Core instance serves, including native APIs such as GPT Realtime,
image generation with Nano Banana and SAP RPT-1. Run it on your laptop with npm, on a Docker host with Compose, or on SAP BTP Kyma, with single
sign-on, API keys per user, usage and SAP cost analytics, quotas, teams, tool policies, pseudonymization and SIEM export in the Admin
Cockpit. And state-of-the-art grounding on OpenAI's own file_search API: every user uploads their own files, searched with
structure-aware chunking, contextual retrieval, hybrid search and reranking.

Bring your own providers: OpenAI, Azure OpenAI, Anthropic and AWS Bedrock accounts as Connections next to SAP AI Core,
priced, published and governed like SAP traffic, with their spend per connection; several SAP AI Core tenants switched
in the cockpit without a restart, cost per tenant. Web search for your agents runs on SAP AI Core, never from the user's
machine. And every API is documented: the gateway, the admin OData and REST APIs in one OpenAPI reference.

Give it a try:
npm install -g @st-gr/sail-proxy (the lite edition on your laptop; the full stack runs on Docker or Kyma)

Docs and tutorials: https://st-gr.github.io/sail-proxy/
Code (AGPL-3.0): https://github.com/st-gr/sail-proxy
