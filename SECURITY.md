# Security Policy

If you discover a security issue, please bring it to our attention right away!

## Reporting a Vulnerability
 
Please **DO NOT** report a security vulnerability in a public issue or in Discussions; instead send your report privately to **llmproxy.security.aide042@slmail.me**. This will help ensure that any vulnerabilities that are found can be [disclosed responsibly](https://en.wikipedia.org/wiki/Responsible_disclosure) to any affected parties.

## Supported Versions

sail-proxy is before 1.0: security fixes are released for the latest release only, as a new version of the npm package and the container images. Please check that the issue still occurs on the latest release (see the [Changelog](CHANGELOG.md)) before reporting; [Upgrade](https://st-gr.github.io/sail-proxy/deploy/backup-and-upgrade) describes how to move to it.
