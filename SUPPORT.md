# Support and Help

Need help getting started with sail-proxy or using it? Here's how.

## How to get help

1. :book: **Read the documentation.** The [sail-proxy documentation](https://st-gr.github.io/sail-proxy/) covers the quick start, every deployment option (standalone CLI, Docker Compose, SAP BTP Kyma), the supported clients and the configuration. Start with [Troubleshooting](https://st-gr.github.io/sail-proxy/guide/troubleshooting) and the [FAQ](https://st-gr.github.io/sail-proxy/guide/faq).

1. :mag: **Search** the existing [discussions](https://github.com/st-gr/sail-proxy/discussions) and [issues](https://github.com/st-gr/sail-proxy/issues). Someone may have had the same problem.

1. :pray: **Ask in [Discussions Q&A](https://github.com/st-gr/sail-proxy/discussions/categories/q-a).** This is the place for questions about setting up, configuring and using sail-proxy. Mark the reply that solved it as the answer, so the next person finds it. Ideas and feature proposals go to [Ideas](https://github.com/st-gr/sail-proxy/discussions/categories/ideas).

1. :beetle: **Open an [issue](https://github.com/st-gr/sail-proxy/issues/new/choose)** only for a reproducible bug or a concrete feature request, using its template. If you are not sure whether it is a bug, start in Q&A; a confirmed bug is turned into an issue.

## What to include

Questions with these details get answered fastest:

- the sail-proxy version (`sail-proxy --version` or the image tag)
- how you deploy: standalone CLI, Docker Compose or SAP BTP Kyma
- the client (Claude Code, Codex, Open WebUI, …) and the model
- what you did, what you expected and what happened, with the error or the log lines around it, in code blocks

## Never post

Discussions and issues are public, and an edit does not remove the original from the history. **Do not** post:

- your SAP AI Core service key, client secrets, sail-proxy API keys or tokens
- personal data from prompts or payload logs
- your AI Core host, deployment IDs or internal hostnames

Replace them with placeholders such as `sk-...`, `<your-host>` or `Jane Doe`.

Security vulnerabilities are never reported in public: follow the [Security Policy](./SECURITY.md).

## What NOT to do

Please **do not** do any of the following:

1. :x: Do not reach out to the author or contributors on X, formerly known as Twitter (or other social media) by tweeting or sending a direct message.

1. :x: Do not email the author or contributors with usage questions.

1. :x: Do not open duplicate issues or litter an existing issue with +1's. Use a [reaction](https://github.blog/2016-03-10-add-reactions-to-pull-requests-issues-and-comments/) instead.

Public questions get public answers, which benefits everyone in the community. ✌️

## Customer Support

sail-proxy is an open-source project maintained in spare time. Help is best-effort; there is no commercial support and no response time. sail-proxy is neither developed nor endorsed by SAP SE, so SAP support cannot help with it either.
